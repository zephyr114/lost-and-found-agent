# 需求文档

## 1. 项目概述

失物招领智能平台（Lost-and-Found Intelligent Platform）是一个支持失物发布、招领发布、智能匹配、消息沟通和管理员审核的失物招领网站。

## 2. 用户角色

| 角色 | 说明 |
| --- | --- |
| 普通用户 | 发布丢失 / 捡到物品信息、搜索、申请认领、消息沟通、举报 |
| 管理员 | 审核信息、处理举报、管理用户、公告、查看统计与日志 |
| 智能 Agent | 自动解析物品属性、搜索相似物品、计算匹配度、通知用户、风险审查 |

## 3. 功能清单

### 用户系统（第二阶段）
- 手机号 / 邮箱注册，用户名 / 邮箱 / 手机号登录
- JWT 认证，个人资料修改，密码修改
- 用户角色（user / admin）、信用分、账号禁用

### 失物招领（第三阶段）
- 发布失物 / 招领（名称、类别、颜色、品牌、时间、地点、坐标、描述、图片）
- 发布后进入审核状态；公开列表仅展示已审核物品
- 关键词 / 类别 / 地点 / 类型 / 时间筛选，最新 / 最早 / 距离排序
- 物品详情、编辑（重新审核）、删除、图片上传（jpg/png/webp/gif，单张 ≤5MB，最多 6 张）

### 认领与消息（第四阶段）
- 对招领物品提交认领申请（特征说明、证明图片、联系方式）
- 发布者处理：同意（其余申请自动拒绝）/ 拒绝 / 要求补充证明
- 站内消息：系统通知、私信、未读数、已读状态

### 智能 Agent（第五阶段）
- 属性提取（规则引擎 + 可选 LLM）、相似物品搜索
- 匹配打分（类别 30 / 名称 15 / 颜色 10 / 品牌 10 / 时间差 15 / 距离 15 / 特征 15，共 100）
- 匹配原因中文解释、自动通知（发布后与审核通过后触发）、风险关键词人工审核建议
- Agent 执行日志（工具级记录）

### 管理后台（第六阶段）
- 数据统计（ECharts）、信息审核、用户管理（禁用 / 启用）
- 认领申请总览、举报处理、系统公告管理
- Agent 运行日志、操作审计日志

## 4. MVP 范围

已实现：用户注册登录、发布失物 / 招领、物品搜索、物品详情、认领申请、基础智能匹配、管理员审核。

暂不实现：实时聊天、复杂图像识别、地图轨迹、多语言、移动端 App、复杂信用体系。

## 5. 验收指标

- 用户注册登录成功率 ≥ 99%；物品发布成功率 ≥ 99%；图片上传成功率 ≥ 95%
- 搜索响应时间 ≤ 2s；智能匹配响应时间 ≤ 5s（本机 SQLite 实测毫秒级）
- 匹配结果可解释（附中文理由）；管理员可完成完整审核流程
- 核心接口均有错误处理（401/403/404/409/422 语义清晰）
- 一键启动（Docker Compose）；README 完整可指导运行
