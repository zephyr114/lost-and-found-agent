# 匹配算法离线评测报告

- 评测集：100 组失物/招领，每组 1 个真实匹配 + 10 个**困难负样本**（共 1100 对）
- 困难负样本：4 个「同款同色同地点、描述略有差异」的近重复 + 同类别不同颜色 + 同颜色不同类别 + 同款但时间差很远
- 真实匹配带噪声：地点 50% 不同、时间差 0~4 天、品牌 20% 缺失
- 评测对象：`calculate_match_score`（类别 / 名称 / 颜色 / 品牌 / 时间 / 距离 / 特征 7 维加权）
- 随机种子：20261109（可复现）

## 排序指标（每组 1 正 + 10 负）

| 指标 | 数值 |
| --- | --- |
| Recall@1 | 0.990 |
| Recall@3 | 1.000 |
| Recall@5 | 1.000 |
| MRR | 0.995 |
| 未召回组数 | 0 |

| 类型 | 平均分 |
| --- | --- |

## 结论

- 在 1:10 困难负样本下，真实匹配排第一的比例为 **99%**，前三名 **100%**，前五名 **100%**。
- 真匹配平均得分 **99.2**，困难负样本平均 **70.4**，且真匹配最低分仍有 **95.0**，分数区分度稳定。
- 对于「同款同色同地点」的近重复物品，模型主要依靠标题与描述的语义差异来区分——这也是真实场景中最难的一类情况。
- 阈值提高到 90 时，越界的平均候选数从 10.0 降到 2.8，同时真匹配通过率仍为 **100%**，说明提高阈值可以「只筛掉干扰、不误伤真实匹配」。
- 实际产品展示 Top-5 推荐，用户无需浏览全部候选；阈值 40 作为「生成匹配记录」的底线，保证不漏掉真实匹配。
